# The One Project

## Overview

The One Project is a digital ecosystem that combines:

- Public Website CMS
- Membership Platform
- Digital Library
- Knowledge Management System
- AI Research Platform

## Architecture

The project follows Clean Architecture principles.

## Technology Stack

Backend:
- ASP.NET Core
- PostgreSQL

Frontend:
- Next.js

Mobile:
- Flutter

AI:
- MCP Server Integration
